# AWS DevOps React CI/CD Pipeline

## Project Overview

This project demonstrates an end-to-end DevOps workflow for deploying a React Todo application on an AWS EC2 Ubuntu instance. The implementation includes Linux administration, React deployment, PM2 process management, Nginx reverse proxy configuration, Jenkins CI/CD automation, Amazon S3 artifact storage, Shell Scripting, Docker, and Docker Compose. It follows a structured DevOps challenge covering deployment automation and infrastructure management. :contentReference[oaicite:0]{index=0}

## Project Workflow

1. Create a sudo user in Ubuntu
2. Install Node.js & npm
3. Clone the React Todo application
4. Build the React project
5. Deploy using PM2
6. Configure Nginx Reverse Proxy
7. Configure UFW Firewall
8. Install and Configure Jenkins
9. Create Jenkins CI/CD Pipeline
10. Upload build artifacts to Amazon S3
11. Dockerize the application
12. Deploy using Docker Compose
